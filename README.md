# 🏠 Hostel Attendance Management System

## 📌 Project Overview

The **Hostel Attendance Management System** is a location-based attendance management application developed to provide a secure and efficient way to manage hostel student attendance. This project was developed during my **3rd year of Diploma** with the aim of replacing manual attendance methods with a digital and reliable solution.

The system introduces a **unique PIN-based attendance mechanism** where attendance can only be marked using a PIN generated and shared by the warden. To prevent unauthorized attendance marking, the application verifies the user's **specific hostel location**, ensuring that attendance is recorded only from the authorized premises.

The system provides separate access for **Students, Wardens, and Admins**, allowing secure attendance management and real-time monitoring.

---

## 🚀 Features

### 👨‍🎓 Student Module
- Students can mark attendance using the unique PIN provided by the warden.
- Location-based verification ensures attendance is submitted only from the authorized hostel area.
- Prevents fake or remote attendance marking.
- Secure and simple attendance submission process.

### 👨‍💼 Warden Module
- Warden can generate unique attendance PINs.
- Shares the generated PIN with students for attendance marking.
- Controls and manages the daily attendance process.
- Ensures secure attendance collection.

### 🛡️ Admin Module
- Admin can access complete hostel attendance records.
- View student-wise attendance details.
- Monitor:
  - ✅ Present students
  - ❌ Absent students
  - 📅 Attendance history
- Helps in efficient hostel attendance management.

### 🔐 Authentication
- User registration and login functionality implemented.
- Secure user authentication using Firebase Authentication.
- Real-time storage and retrieval of attendance data using Firebase Database.
